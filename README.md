# RSA Algorithm – Cryptography Using Python

## Project Overview

This project is part of my cryptography learning, where I implemented the RSA algorithm using Python and SageMath.

The aim was to understand how public-key cryptography works and how mathematical concepts such as prime numbers, modular arithmetic, and modular inverses are used to encrypt and decrypt messages.

## What I Implemented

- Created a function to generate RSA public and private keys.
- Calculated the modulus (n) using two prime numbers.
- Calculated Euler's totient value (φ).
- Used modular inverses to generate the private key.
- Developed separate functions for encryption and decryption.
- Tested RSA encryption and decryption using numerical messages.
- Verified that the decrypted message matched the original message.

## What I Learned

Through this project, I gained a better understanding of asymmetric encryption and how RSA uses public and private keys.

I learned how mathematical operations can be applied in programming to encrypt messages and recover the original information using decryption.

This activity also helped me improve my Python skills by working with functions, mathematical calculations, and testing code.
